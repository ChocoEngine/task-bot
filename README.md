# Task Bot

Бот со списком задач на Kotlin для Telegram и Яндекс Мессенджера. Список
отдельный для каждого личного или группового чата.

## Команды

- `/add текст` — добавить задачу;
- `/list` — показать задачи (`✅` выполнена, `❌` не выполнена);
- `/done номер` — отметить задачу выполненной;
- `/delete номер` — удалить задачу;
- `/clear_done` — удалить все выполненные задачи;
- `/help` — справка.

В одном чате можно хранить не более 50 задач. При достижении лимита бот не
добавляет новые задачи и предлагает удалить ненужные либо очистить выполненные
командой `/clear_done`. `/list` также показывает не более 50 записей.

## Запуск

1. Впишите токен выбранного мессенджера в локальный файл `.env`. Он уже добавлен
   в `.gitignore` и не попадёт в репозиторий.
2. Ограничьте доступ к файлу: `chmod 600 .env`.
3. Выберите транспорт через `BOT_TRANSPORTS` и запустите `./gradlew run`.

По умолчанию запускается Telegram (`BOT_TRANSPORTS=telegram`). Для Яндекс
Мессенджера укажите:

```dotenv
BOT_TRANSPORTS=yandex
YANDEX_MESSENGER_TOKEN=токен-бота
```

Для одновременной работы укажите `BOT_TRANSPORTS=telegram,yandex` и оба токена.
Токен Яндекс Мессенджера создаётся в [кабинете Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/messenger/bot-platform).
Адаптер использует polling, поэтому у бота не должен быть настроен webhook.
Бот должен состоять в групповом чате; в личном чате он отвечает сотрудникам
своей организации.

Задачи сохраняются в базе SQLite `data/tasks.db`, поэтому не исчезают после
перезапуска. Путь можно изменить через `TASKS_DATABASE` в `.env`.

## Общая база и другие мессенджеры

Бизнес-логика не зависит от транспорта. Адаптеры преобразуют входящие сообщения
в `IncomingMessage` и используют один `TaskService` и одно хранилище.

По умолчанию у каждого чата собственный список. Чтобы два чата разных платформ
использовали один список и одну SQLite-базу, задайте `TASK_SCOPE_OVERRIDES`, например:

```dotenv
TASK_SCOPE_OVERRIDES=telegram:-1001234567890=family,yandex:0/0/some-chat=family
```

В личном чате Яндекс Мессенджера ключ списка имеет вид `yandex:private:<id пользователя>`.
